# Chaitali Jani — Portfolio

A static portfolio made with HTML, CSS and JavaScript. No paid services, external fonts, tracking, build tools or plugins are required.

## Preview
Open index.html in a browser. The email button opens the visitor's email app; Copy email has a text fallback if browser permissions prevent copying.

## Files
- index.html: all project descriptions and links
- styles.css: desktop and mobile styles
- script.js: email-copy interaction
- portrait.png: supplied portrait
- resume.pdf: resume download

## Before publishing
Review your contact email, portrait, resume and project descriptions: these will be public. The two-page resume contains no photograph or phone number. Confirm which employer/client work can be displayed publicly. Project panels are labelled illustrations, not screenshots.

## Free hosting
This folder is ready for GitHub Pages. Publishing requires your GitHub account and a repository with Pages enabled. No custom domain is necessary. Nothing has been published by creating these files.
